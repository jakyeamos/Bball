# NBA Draft Simulator

This is a monorepo for the NBA Draft Simulator application.

## Packages

-   `client`: React frontend for the application.
-   `server`: Node.js backend for the application.
-   `shared`: Shared types and constants between the client and server.

## Getting Started

To get started, install the dependencies at the root of the project:

```
npm install
```

Then, you can run the client and server concurrently:

```
npm run dev
```
